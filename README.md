# 📊 Day 08 - Grid Gallery Dashboard

A full dashboard layout with sidebar navigation, stats cards, image gallery, bar chart, and notifications — all built with CSS Grid.

## What I Learned
- CSS Grid for full-page dashboard layout
- Sidebar navigation with fixed positioning
- Grid `auto-fill`, `minmax`, `span` for dynamic gallery
- Dashboard stat cards
- CSS-only bar chart
- Notification feed component
- Filter tabs
- Responsive breakpoints for grid layouts

## How to View
Open `index.html` in any web browser.
